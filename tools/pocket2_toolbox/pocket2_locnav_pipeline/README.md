# Pocket2 Loc & Nav Pipeline

Offline processing pipeline for localization and navigation using reconstructed point clouds from Pocket2 handheld scanning device.

## Directory Structure

pocket2_loc_nav_pipeline/
├── pcd2keyframe.py        # Keyframe extraction (for Fast-LIVO2 localization)
├── pcd2pcd.py             # Global map downsampling (for Fast-LIVO2 localization)
├── pcd2ply.py             # Point cloud format conversion (for grid map generation)
├── grid_map_gen.py        # Grid map generation (for Nav2 navigation)
└── config_grid_map.json   # Grid map generation configuration

## External Data Files

- `MTxxxx/image/img_pos_opt.txt` - Optimized pose file (generated by MindCloudApp)
  - Format: `frame_id timestamp x y z qw qx qy qz`
- `MTxxxx/map/keyframe_pose.txt` - Keyframe pose file (copied from `MTxxxx/image/img_pos_opt.txt`)

## Processing Workflow

### 1. Keyframe Extraction (Fast-LIVO2 Localization)

**Function**: Extract keyframe point clouds from the global point cloud, containing points visible from each keyframe perspective.

**Input**:
- `MANIFOLD_MTxxxx-Cloud_Opt.pcd` - Global point cloud (must contain `label` field)
- `MTxxxx/map/keyframe_pose.txt` - Keyframe pose file (copied from `MTxxxx/image/img_pos_opt.txt`)

**Output**:
- `MTxxxx/map/keyframe_cloud/` - Keyframe point cloud directory (`xxxxxx.pcd` format)

**Usage**:
```bash
python pcd2keyframe.py
# Or edit paths in the script
```

### 2. Global Map Downsampling

**Function**: Downsample the global point cloud for Fast-LIVO2 localization matching.

**Input**:
- `MANIFOLD_MTxxxx-Cloud_Opt.pcd` - Global point cloud

**Output**:
- `MTxxxx/map/cloudGlobal.pcd` - Downsampled global map

**Usage**:
```bash
python pcd2pcd.py
# Edit paths and voxel_size in the script
```

### 3. Point Cloud Format Conversion (PLY)

**Function**: Convert PCD format to PLY format for grid map generation.

**Input**:
- `MANIFOLD_MTxxxx-Cloud_Opt.pcd` - Global point cloud

**Output**:
- `MTxxxx/map/cloudGlobal.ply` - PLY format point cloud

**Usage**:
```bash
python pcd2ply.py
# Edit paths and voxel_size in the script
```

### 4. Grid Map Generation (Nav2 Navigation)

**Function**: Convert point cloud to 2D grid map for Nav2 navigation.

**Input**:
- PLY or PCD format point cloud file
- `config_grid_map.json` - Configuration file

**Configuration Parameters**:
- `origin_file_directory` - Point cloud file directory
- `origin_file_name` - Point cloud filename (without extension)
- `rotation_matrix` - Rotation matrix
- `thre_z_min / thre_z_max` - Height filter range
- `flag_pass_through` - Enable/disable pass-through filter
- `thre_radius / thres_point_count` - Radius outlier filter parameters
- `map_resolution` - Grid map resolution
- `map_file_name` - Output map filename

**Output**:
- `.pgm` - Grid map image
- `.yaml` - Map metadata

**Usage**:
```bash
python grid_map_gen.py
```

### [Optional] 5. Grid Map Manual Editing

The generated grid map may have some false detections or missed areas that can be manually corrected using GIMP.

**Tool Requirements**: GIMP (open source image editor)

**Important Notes**:
- **Do NOT** adjust image resolution or rotation
- **Do NOT** modify the `grid_map.yaml` file
- Only edit the obstacle cells in the `.pgm` file

**Usage**:
1. Open `grid_map.pgm` with GIMP
2. Use the **Pencil Tool** to draw obstacles (paint the area black)
3. Use the **Eraser Tool** to remove false detections (paint the area white)
4. Save the modified `.pgm` file

## Recommended Execution Order

1. Copy `MTxxxx/image/img_pos_opt.txt` → `MTxxxx/map/keyframe_pose.txt`
2. **pcd2keyframe.py** → Prepare keyframes for localization
3. **pcd2pcd.py** → Prepare localization map
4. **pcd2ply.py** → Convert to PLY format
5. **grid_map_gen.py** → Generate navigation grid map
6. **[Optional] Manual editing** → Use GIMP to correct the grid map

## Loc & Nav Map Deployment

The generated grid map needs to be deployed to the robot for navigation. Here are the deployment configuration steps:

### 1. Map File Placement

Place the generated map files to the path specified in the navigation configuration:

```
/workspace/map/
├── grid_map/           # Navigation grid map
│   ├── grid_map.yaml    # Map metadata
│   └── grid_map.pgm     # Grid map image
├── cloudGlobal.pcd      # Downsampled point cloud map for localization
├── keyframe_cloud/      # Keyframe point cloud directory
│   ├── 000000.pcd
│   ├── 000001.pcd
│   └── ...
└── keyframe_pose.txt    # Keyframe pose file
```

### 2. Configuration File Modification

The localization and navigation map path is configured in `navigation2.launch.py`:

**File Path**: `nav_agent/humble_localization_nav2/g1_navigation2/launch/navigation2.launch.py`

**Configuration** (Line 39):
```python
map_dir = LaunchConfiguration(
    'map',
    default=os.path.join('/workspace/map/grid_map/grid_map.yaml'))
```

### 3. Localization Map Configuration

Fast-LIVO2 localization needs to configure the localization map path in `mid360_online_reloc.yaml`:

**File Path**: `nav_agent/humble_localization_nav2/lio_mapping_loc/config/mid360_online_reloc.yaml`

**Configuration** (Line 4):
```yaml
priorDir: "/workspace/map/"
```

### 4. Verify Deployment

Start the navigation node to confirm the map loads correctly:
```bash
ros2 launch g1_navigation2 navigation2.launch.py
```
